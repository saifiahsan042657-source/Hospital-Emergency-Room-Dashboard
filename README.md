# 🏥 Hospital Emergency Room Dashboard

## 📌 Project Overview
This project presents an interactive **Hospital Emergency Room Dashboard** built in **Microsoft Excel**. It helps analyze patient visits, waiting time, satisfaction, admissions, demographics, and department referrals through interactive charts and KPIs.

## 🎯 Objective
The objective of this dashboard is to provide hospital management with actionable insights to improve patient care, reduce waiting time, and support better decision making.

## 🛠️ Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## 📊 Dashboard Features
- Total Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Admission Status Analysis
- Age Group Distribution
- Gender Distribution
- Patients Attended Within Time vs Delay
- Department Referral Analysis
- Interactive Year and Month Filters

## 📈 Key Insights
- Track monthly patient volume.
- Monitor average waiting time.
- Measure patient satisfaction.
- Compare admitted and non-admitted patients.
- Analyze patient demographics.
- Identify the most referred hospital departments.
